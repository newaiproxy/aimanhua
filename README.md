## AI漫画提示词怎么写？

可以按这个公式写：

`生成【漫画类型】， 主角是【人物/物体/品牌/角色】， 场景是【地点/氛围/时代背景】， 画风采用【二次元/漫画/水彩/赛璐璐/蜡笔/韩风手绘】， 画面要有【镜头语言/情绪/光影/构图】， 适合用于【头像/封面/海报/分镜/社媒配图】。`

如果是上传照片转漫画，重点加这几句：

`保留人物五官、发型、脸型和辨识度。 保留原图核心构图和可识别元素。 将整体重新诠释为漫画/动画/插画风格。`

## AI漫画生成小技巧

如果人物不像本人，加：

`保留人物真实五官、脸型、发型和辨识度，不要改变人物身份。`

如果画面太写实，加：

`重新诠释为漫画插画风格，线条清晰，色彩更有动画感。`

如果画面太乱，加：

`背景简洁，主体突出，构图清晰，不要过多杂物。`

如果想更像漫画分镜，加：

`加入清晰分镜结构，角色动作和表情有连续变化，画面有故事推进感。`
